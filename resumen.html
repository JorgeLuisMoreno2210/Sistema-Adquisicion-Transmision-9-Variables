Resultados
Diseño e implementación de un sistema supervisor de signos vitales y posición para grupos de deportistas, basado en el Internet de las cosas.

Resumen

Este trabajo de grado está enfocado en el área del internet de las cosas propone el desarrollo de unos dispositivos electrónicos que permite realizar la lectura de temperatura, ritmo cardiaco y geoposición de un deportista en tiempo real. Para realizar este sistema se ha tenido en cuenta el protocolo de comunicación ESP NOW, este se utiliza para comunicar las ESP encargadas de hacer las mediciones de los signos vitales y la geoposición con el fin de enviar los datos muestreado a otra ESP que funciona con el mismo protocolo de comunicación. Los datos recibidos serán mostrados en una interfaz gráfica, de tal manera que el entrenador o encargado pueda monitorear a cada deportista que lleve puesto el dispositivo.

Para realizar este sistema se ha hecho una profunda revisión del estado del arte de proyectos que han trabajado en la misma área, así mismo se lograron definir los tipos de sensores, microcontroladores, modulo GPS y el protocolo de comunicación para el correcto funcionamiento del sistema. Como resultado el dispositivo presentara una interfaz de usuario que, al oprimir un botón en esta, se visualizara el estado del deportista y de la misma manera su geoposición cumpliendo a cabalidad sus objetivos.

¿Qué es el sistema de supervisión?

Este proyecto es una herramienta diseñada para monitorear y registrar la actividad física y la posición de los deportistas durante los entrenamientos o rutinas deportivas. El sistema se compone de una serie de dispositivos portátiles que se colocan en el cuerpo del deportista para medir la frecuencia cardíaca, la temperatura corporal, la posición y otros signos vitales.

¿Cómo funciona el sistema?

El sistema de supervisión utiliza tecnología de sensores y comunicación inalámbrica para enviar los datos de los signos vitales y la posición del deportista a una red local centralizada. La plataforma de software procesa los datos y los presenta en una interfaz gráfica de usuario que permite a los entrenadores y los usuarios realizar un seguimiento y análisis de la actividad física los deportistas.

Beneficios del sistema de supervisión

  • Mejora la seguridad y la salud de los deportistas.
  • Permite un monitoreo en tiempo real de la actividad física.
  • Facilita la toma de decisiones por parte de los entrenadores y los médicos del equipo.
  • Permite el análisis de los datos para mejorar la eficacia del entrenamiento y la recuperación de lesiones.
